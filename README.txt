OilControl Web — қазақ тіліндегі адаптивті веб-прототип.

Қолдану:
1) index.html файлын браузерде ашыңыз.
2) iPhone: Safari; Android: Chrome.
3) QR-кодпен кез келген телефоннан ашу үшін сайтты интернетке жариялап, HTTPS сілтемесін алу қажет.

GitHub Pages немесе Netlify сияқты статикалық хостингке осы index.html файлын жүктеуге болады.
Барлық көрсеткіштер — демонстрациялық. Нақты датчиктерге немесе өндірістік жабдыққа қосылмаған.
